# SherrByte 2.0 — Complete Deploy Guide
# Total time: ~30 minutes. Zero rupees.

## STEP 1: Supabase (your database)

1. Go to https://supabase.com → Sign Up (use GitHub)
2. New Project → name: `sherrbyte` → choose a DB password (save it!) → Region: Singapore → Free plan
3. Wait ~2 min for it to spin up
4. Go to Settings → Database → Connection string → Transaction pooler (port 6543)
5. Copy the URL — looks like:
   `postgresql://postgres.XXXXX:YOUR_PASSWORD@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres`
6. Save this as your DATABASE_URL

## STEP 2: Gemini API Key (free AI)

1. Go to https://aistudio.google.com/app/apikey
2. Click "Create API key" → Copy it
3. Free tier: 250 requests/day — more than enough

## STEP 3: Groq API Key (free AI fallback)

1. Go to https://console.groq.com/keys → Sign up
2. Create API Key → Copy it

## STEP 4: Deploy Backend to Render

1. Create a new GitHub repo called `sherrbyte-backend`
2. Copy all files from the `backend/` folder into it
3. Push to GitHub:
   ```
   git init
   git add .
   git commit -m "SherrByte 2.0 backend"
   git remote add origin https://github.com/YOUR_USERNAME/sherrbyte-backend.git
   git push -u origin main
   ```
4. Go to https://render.com → Sign Up → New → Blueprint
5. Connect your `sherrbyte-backend` repo → it reads `render.yaml` automatically
6. Click Apply

7. After deploy starts, go to your service → Environment tab → Add these:

   | Key | Value |
   |-----|-------|
   | DATABASE_URL | (your Supabase URL from Step 1) |
   | CORS_ORIGINS | http://localhost:3000 (add Vercel URL after Step 6) |
   | GEMINI_API_KEY | (from Step 2) |
   | GROK_API_KEY | (from Step 3) |

   JWT_SECRET is auto-generated by Render — leave it.

8. Save → Render redeploys automatically (~3 min)

9. Your backend URL will be something like:
   `https://sherrbyte-backend-XXXX.onrender.com`

## STEP 5: Verify Backend Works

Open these in your browser (replace with your actual URL):

- `https://YOUR-RENDER-URL.onrender.com/` → should show `{"name":"SherrByte API","version":"6.0.0","status":"ok"}`
- `https://YOUR-RENDER-URL.onrender.com/healthz` → should show `{"status":"ok"}`
- `https://YOUR-RENDER-URL.onrender.com/health` → shows full stats

If you see errors, check the Render logs tab.

## STEP 6: Deploy Frontend (index.html) to Firebase

This is your working app TODAY. Open `frontend/public/index.html`:

Find line:
```js
const API_URL = "https://sherrbyte-backend-v2.onrender.com";
```

Replace with your actual Render URL:
```js
const API_URL = "https://YOUR-ACTUAL-RENDER-URL.onrender.com";
```

Then deploy to Firebase (you already have Firebase set up):
```
cd frontend/public
firebase deploy
```

Your app is live at your Firebase URL!

## STEP 7: Deploy Next.js Frontend to Vercel (optional upgrade)

1. Create a new GitHub repo called `sherrbyte-frontend`
2. Copy all files from the `frontend/` folder into it
3. Create `.env.local` file in the root:
   ```
   NEXT_PUBLIC_API_URL=https://YOUR-RENDER-URL.onrender.com
   ```
4. Push to GitHub
5. Go to https://vercel.com → New Project → Import your repo
6. Framework: Next.js (auto-detected)
7. Add Environment Variable: `NEXT_PUBLIC_API_URL` = your Render URL
8. Deploy → ~2 min

9. After Vercel deploys, go back to Render → Environment → Update CORS_ORIGINS:
   ```
   https://YOUR-APP.vercel.app,http://localhost:3000
   ```

## STEP 8: Keep Backend Warm (free)

Render free tier sleeps after 15 min idle. Fix for free:

1. Go to https://cron-job.org → Sign up free
2. Create Cronjob:
   - URL: `https://YOUR-RENDER-URL.onrender.com/healthz`
   - Schedule: Every 14 minutes
3. Save — your backend stays warm permanently

## STEP 9: Test Everything

1. Open your app (Firebase URL or Vercel URL)
2. Create an account
3. Select topics in onboarding
4. Wait 1-2 min for first RSS collection cycle
5. Pull to refresh — articles should appear!

Check backend logs to see:
```
[RSS] Collected 800+ raw from 51 feeds
[DEDUP] 500+ unique articles
[DB] 400+ new articles inserted
[AI] Processing 4 articles via gemini
```

## Troubleshooting

**"DB init failed"** → Wrong DATABASE_URL format. Must use Transaction pooler (port 6543) not Direct connection (port 5432)

**"JWT_SECRET is placeholder"** → Render should auto-generate. If not, run:
```
python -c "import secrets; print(secrets.token_urlsafe(48))"
```
And paste output as JWT_SECRET in Render env vars.

**Frontend shows "Couldn't reach server"** → API_URL in index.html is wrong or CORS_ORIGINS doesn't include your frontend domain

**No articles appearing** → Backend is still on first collection cycle. Wait 2 minutes, refresh.

**Render sleeping** → Set up cron-job.org (Step 8)
